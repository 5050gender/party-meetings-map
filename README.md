# Party Meetings Map

A live map of house-meeting/event listings scraped from party websites
(Bennett 2026 / Yachad, and Yashar! with Eisenkot). Click a pin for the
meeting details and a link to register on the party's own page.

Generated by a scraper — this repo holds only the published site
(`index.html` + the local `vendor/` copy of Leaflet). The scraper source
lives in a separate project folder and is not published here.
